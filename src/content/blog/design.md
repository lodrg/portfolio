当然我带了一下颜色字体和网格系统

## 整体逻辑

进行设计的时候整体是从上到下的建立系统（统一性）

然后从下到上的完成组件的逻辑（亲近性）

组件需要一个一个的被构造和组织（亲近性，相关联元素间距小，不相关的间距大）

这里就需要一个构造单体元素的步骤的问题

最后做的是基于 ui，来进行 ux 设计

## 单个元素的构建逻辑

1.各自先把内容摆上来（比如图标，卡片，文字）

2.然后都选中进行 auto layout （shift + a）这个快捷键会自动进行 frame 组合并添加自动布局

3.然后配置 layout 确定间隔边距等

4.auto layout 中的 aligment 决定了 frame 内部的布局，在这种层层嵌套的逻辑里面是排版逻辑的核心

5.这里有一个子问题就是关于间距的数字的问题，这里需要更精细的内容

6.这里可能会设置背景颜色，使用颜色系统中的内容就可以

7.最终会把每一个单个元素组合起来层层 auto，这里是一个自下向上的过程


## button 的构建逻辑

button 的逻辑是用文字，转 frame（co+g），然后基于这个 frame设置圆角，auto layout 和按钮颜色以及文字颜色。

## frame 是什么

容器，优先使用，主要是可以 auto layout
